# Agora — Specs (Spec Kit)

Spec-driven development: every feature starts as a spec, becomes a plan,
then a task list, then GitHub issues. See `spec-driven.md` for the
methodology and `AGENTS.md` for the rules.

## Conventions

- Directory: `specs/<NNN>-<kebab-name>/`
- Files: `spec.md` (mandatory), `plan.md`, `tasks.md` (generated later)
- Status in spec front matter: `Draft → In Review → Approved`
- One feature = one directory; amendments update the same spec (never a
  copy)
